📻 单页面 P2P 音频文件 → <audio> 标签 demo

🎚️ 场景（全部在本页面内完成，无需双 tab / 无需服务器信令）：

  1. ⏳ 点击开始后延时 10 秒，才把流发送到对端
  2. 📤 页面内创建 发送端 pc1：加载音频文件 → 解码 → 生成 MediaStream → addTrack
  3. 📥 同时创建 接收端 pc2：ontrack 收到轨道
  4. 📶 pc1 ↔ pc2 本地直连（offer/answer/ICE 全部在页面内回调，走本机 loopback）
  5. 🔇 接收端用 <audio> 标签 播放，play 时 muted = true
  6. 🔊 10 秒后 自动 muted = false（恢复声音）

URL: https://localhost/audio_file_p2p.html
